# چک‌لیست انتشار تجاری Orbit Breaker

## قبل از انتشار

- یک application ID نهایی و متعلق به خودتان جایگزین `com.orbitforge.orbit_breaker` کنید.
- آیکن نهایی 512×512، feature graphic و حداقل چهار اسکرین‌شات واقعی تهیه کنید.
- keystore انتشار را خارج از repository بسازید و تنظیمات امضا را در `android/key.properties` قرار دهید.
- نسخه را روی چند گوشی ضعیف، متوسط و نمایشگرهای 60/90/120Hz تست کنید.
- نام، توضیح کوتاه و توضیح کامل فارسی/انگلیسی برای مارکت آماده کنید.
- فرم رده‌بندی سنی و Data Safety را تکمیل کنید. نسخه فعلی داده شخصی جمع نمی‌کند و فقط رکورد محلی نگه می‌دارد.
- یک صفحه privacy policy عمومی منتشر کنید، حتی اگر جمع‌آوری داده ندارید.

## مدل درآمد پیشنهادی برای نسخه اول

نسخه فعلی برای فروش یک‌باره مناسب است. برای مدل رایگان، تبلیغ اجباری در هر باخت توصیه نمی‌شود؛ rewarded ad اختیاری برای ادامه یک‌باره یا دوبرابرکردن جایزه، همراه با حذف تبلیغ به‌صورت خرید درون‌برنامه‌ای، تجربه سالم‌تری می‌سازد. اتصال تبلیغات و پرداخت باید برای هر مارکت به‌صورت جداگانه و مطابق SDK همان مارکت انجام شود.

## خروجی انتشار

```powershell
flutter clean
flutter pub get
flutter analyze
flutter test
flutter build appbundle --release
```

فایل AAB در `build/app/outputs/bundle/release/app-release.aab` ایجاد می‌شود. برای مارکت‌هایی که APK می‌خواهند:

```powershell
flutter build apk --release --split-per-abi
```

هرگز فایل keystore یا رمزهای آن را commit نکنید.
